# Temporary material

Context and project source own durable meaning. Generated exports, package tarballs, test outputs, file-maintenance journals and optional task handoff notes do not become a second authority.

Use tmp/ty-context for consumer maintenance/export output and .artifacts for source-workspace test/build output. Keep backups outside automatically discovered Skill and default Context paths. Do not scan or convert all historical materials merely because a maintenance task runs.

Cleanup is scoped to owned output. Validate the resolved destination before removing files; do not traverse symlinks/junctions outside the intended root. Never delete unresolved transaction journals, conflict files or unrelated worktrees to make checks pass. Preserve secret redaction and inspect exports before sharing; credentials are not durable Context.
