# Short development contract

The only generic development guidance is the canonical short startup block in .codex/ty-context-managed/agents/AGENTS_CORE.md. Package source sync derives its distribution. Do not duplicate the full wording here or make a Skill a prerequisite to reading it.

The host/agent owns planning, tools, decomposition, parallel work and verification choices within user authorization and project requirements. There is no package completion Gate, role workflow or runtime task state. Existing business, technical, design and security constraints remain authoritative project inputs; tool retirement does not cancel them.

Installation and tests can establish distributed text, not model compliance. AGENTS.override.md and host instruction scope can affect actual loading; doctor reports observable local conditions without claiming to inspect a running model.

The contract routes from affected implementation to owners and current controlling inputs. It includes proportional reuse, shared-responsibility and dependency decisions, plus reading, viewing and implementing adopted design resources within their scope. Detailed resource creation, revision and adoption methods belong to the optional .codex/ty-context-managed/skills/design-resource capability, whose generation/editing route is Stitch. Ordinary implementation does not require that Skill, a Stitch connection or another adoption cycle; existing authorization applies.
