# Short development contract

The only generic development guidance is the canonical short startup block in .codex/ty-context-managed/agents/AGENTS_CORE.md. Package source sync derives its distribution. Do not duplicate the full wording here or make a Skill a prerequisite to reading it.

The host/agent owns planning, tools, decomposition, parallel work and verification choices within user authorization and project requirements. Existing business, technical, design and security constraints remain authoritative project inputs; tool retirement does not cancel them.

Installation and tests can establish distributed text, not model compliance. AGENTS.override.md and host instruction scope can affect actual loading; doctor reports observable local conditions without claiming to inspect a running model.
