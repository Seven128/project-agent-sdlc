# Why the package is small

The project owner replaced the old machine-completion and formal-design product goals with durable project memory plus a short development contract. Long-Task, DSA/DRA, role workflows, exact Fact ledgers, observer proofs, routing rankings and generic source-line gates are retired. Their old proof/ROI requirements do not govern this redesign.

Keep stable Catalog and file-safety owners because they preserve useful facts and protect user files. Remove mechanisms primarily prescribing generic model steps or proving retired promises. This decision is not evidence that a model cannot miss requirements or that a fixed speed improvement occurred.

Nonrecursive default_files was chosen because promoting an implicit architecture default to a default node changes child traversal. Migration compares exact normalized body sets. Offline reading remains possible, and structural checking does not turn arbitrary prose into a dependency.

Future additions should solve a concrete recurring project-memory or maintenance problem in an existing owner, without rebuilding a task workflow or general design platform.
